# Make the AI Judge Laugh: Office Jokes

A single one-line joke about office life, written for the make.fun
competition
[u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a](https://make.fun/c/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a)
("Make the AI Judge Laugh: Office Jokes"). A house AI judge compares the
jokes two at a time, weighing whether the line is a real joke, whether it
turns somewhere unexpected, whether it rings true about the office, how
tight the wording is and how fresh the take is.

## The joke

> I told HR my workload was crushing me, so they signed me up for a workshop called 'Crushing It!'

96 characters, one line. The turn: "crushing me" (the workload is too
much) is misheard as "crushing it" (doing great) — and HR's answer is a
motivational workshop instead of help.

## How it runs

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic: the program always writes the same bytes. It never removes
the output directory itself, only its contents, then writes the single
line. Stdlib only, no network.
